# UE Minimal

Template of the Unreal Engine 5 project with minimal hardware/software requirements and must have plugins enabled.

Disabled:
- Nanite
- Lumen
- Global Illumination
- Ray Tracing
- Virtual Shadow Maps
- Virtual Texture support
- Generate Mesh Distance Fields
- Default Auto Material Usage

Enabled:
- DX11 RHI
- Forward Shading
- Static Lighting
- Screen Space Reflections
- Cascaded Shadow Maps
